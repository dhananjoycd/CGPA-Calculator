# 🎓 Academic CGPA Calculator

Welcome to the **Academic CGPA Calculator** – an elegant, fast, and feature-rich tool designed to help students track their academic performance effortlessly. Whether you're aiming for a tuition waiver, setting goals for corporate jobs, or just want a clear picture of your academic standing, this application is your perfect companion!

## ✨ Key Features

* **⚡ Real-time Live Calculation**: Add unlimited subjects, credits, and grade points to see your CGPA update instantly.
* **💾 Persistent Auto-Save**: Powered by Local Storage, your data remains safely stored in your browser even if you accidentally close the tab. No more re-entering data!
* **🧠 Smart Performance Analysis**: Automatically analyzes and categorizes your grades into performance tiers (Excellent, Very Good, Good, Average, Poor) with color-coded badges.
* **📥 One-Click PDF Report**: Instantly generate and download a beautifully formatted, professional marksheet as a PDF for future reference or sharing.
* **📱 Fully Responsive Design**: Carefully crafted to provide an exceptional user experience on both mobile devices and desktop screens.

## 🛠️ Tech Stack

This project is built using a modern, scalable, and highly optimized tech stack:

* **Frontend Framework**: [React 19](https://react.dev/)
* **Build Tool**: [Vite](https://vitejs.dev/) - For lightning-fast Hot Module Replacement (HMR) and optimized builds.
* **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) - Utility-first CSS framework for a sleek, responsive, and highly customized UI.
* **Icons**: [Lucide React](https://lucide.dev/) - Beautiful and consistent iconography.
* **PDF Generation**: [jsPDF](https://github.com/parallax/jsPDF) & [jsPDF-AutoTable](https://github.com/simonbengtsson/jsPDF-AutoTable) - For generating pristine client-side PDF reports.
* **Language**: TypeScript - For robust, type-safe development.

## 🚀 Getting Started

To run this project locally, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/dhananjoycd/CGPA-Calculator.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd CGPA-Calculator
   ```
3. **Install the dependencies:**
   ```bash
   npm install
   ```
4. **Start the development server:**
   ```bash
   npm run dev
   ```
